ĐỒNG BỘ ĐA THIẾT BỊ

Tiến độ trên mọi thiết bị

Ứng dụng hiện là web tĩnh nên dữ liệu chỉ nằm trên máy đang dùng. Kết nối một Supabase miễn phí để tự đồng bộ tiến độ và bài học cá nhân giữa máy tính, điện thoại và các trình duyệt.

Chỉ dùng anon/publishable key, tuyệt đối không dán service_role key. Mã đồng bộ hoạt động như mật khẩu: ai có mã này có thể xem và cập nhật tiến độ tương ứng.

Chưa cấu hình đồng bộ đám mây.
Thiết lập Supabase miễn phí (làm một lần)
  1. Tạo project Supabase, mở SQL Editor và chạy đoạn SQL bên dưới.
  2. Lấy Project URL và anon/public key trong phần API của project, rồi điền vào đây.
  3. Tạo mã đồng bộ. Trên thiết bị còn lại, nhập cùng URL, key và mã này. Sau đó ứng dụng tự đồng bộ khi mở trang và sau mỗi lần học.
create table if not exists public.english_learning_progress (
  sync_id text primary key,
  payload jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now()
);

alter table public.english_learning_progress enable row level security;
grant select, insert, update on public.english_learning_progress to anon;

drop policy if exists "sync by private code" on public.english_learning_progress;
create policy "sync by private code"
on public.english_learning_progress
for all to anon
-- The app sends its private sync code in the standard x-client-info header.
using (
  sync_id = (coalesce(current_setting('request.headers', true), '{}')::jsonb ->> 'x-client-info')
)
with check (
  sync_id = (coalesce(current_setting('request.headers', true), '{}')::jsonb ->> 'x-client-info')
);
Dữ liệu được lưu cục bộ trước; khi cấu hình cloud, tiến độ và nội dung cá nhân sẽ tự gộp/đồng bộ. Nội dung phân tích không được gửi tới dịch vụ AI.
